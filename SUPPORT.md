# Support

This software is provided without any warranty. However if you run into any problems, we might try to help.

## Update cycles / VuFind version compatibility

The provided repository is typically part of our own infrastructure.
Our internal policy is to upgrade to a new VuFind release approx. between 6-12 months after its release.
This typically means we will add compatibility for new versions within the given timespan.
Providing backwards compatibility with older versions is usually not covered with our work.
However we might be willing to accept pull requests.
Also, we typically only test the plugin against VuFind features which we use by ourself - so if you use very specific features,
the compatibility might not be guaranteed.

## Issues & Pull requests

If you have any feature requests, bug reports or questions, feel free to open an issue.
However, there is no guaranteed reaction time. Depending on workload, vacation, etc. reaction can often take multiple weeks.
If you need any important bugfix, you might want to fix it locally by yourself and open a pull requests as courtesy.
We're open-minded to all kinds of PRs in general, but there is no guarantee of any reaction.
